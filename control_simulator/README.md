# سیمولاتور سیستم کنترلی — دو آردوینو + اسیلوسکوپ

سیمولاتور حلقه‌بسته PID با نمایش دو برد آردوینو (کنترلر و پروسه)، ست‌پوینت، فیدبک، شرایط پروسه، ضرایب **Kp / Ki / Kd** و اسیلوسکوپ زنده.

## اجرای سریع (بدون سخت‌افزار)

```bash
cd control_simulator/web
python3 -m http.server 8080
```

سپس در مرورگر باز کنید: [http://127.0.0.1:8080](http://127.0.0.1:8080)

1. **شروع** را بزنید تا حلقه کنترل اجرا شود.
2. ست‌پوینت و Kp/Ki/Kd را تغییر دهید و موج‌ها را روی اسیلوسکوپ ببینید.
3. شرایط پروسه (بهره، τ، تأخیر، اختلال) را عوض کنید.

## اجزا

| بخش | نقش |
|-----|-----|
| آردوینو ۱ (`Controller_PID`) | محاسبه PID، ارسال فرمان `u` |
| آردوینو ۲ (`Plant_Process`) | مدل مرتبه اول + تأخیر، ارسال فیدبک `y` |
| وب‌اپ `web/` | اسیلوسکوپ و پنل تنظیمات (شبیه‌سازی نرم‌افزاری همان حلقه) |

## سخت‌افزار واقعی

1. اسکچ‌های داخل `arduino/Controller_PID` و `arduino/Plant_Process` را روی دو برد آپلود کنید.
2. UART متقابل + GND مشترک:
   - Controller TX → Plant RX
   - Controller RX ← Plant TX
3. مانیتور سریال هر برد (۹۶۰۰) وضعیت حلقه را نشان می‌دهد.

### پروتکل متنی

```
U:<float>     # فرمان کنترل (کنترلر → پروسه)
Y:<float>     # فیدبک (پروسه → کنترلر)
SP:<float>    # ست‌پوینت
KP:/KI:/KD:   # ضرایب PID
GAIN:/TAU:/DIST:/DELAY:  # شرایط پروسه
```

## مدل ریاضی

پروسه: \(\dot{y} = (-y + K\cdot u_{delayed} + d)/\tau\)

کنترلر: \(u = K_p e + K_i\int e\,dt + K_d \dot{e}\) با \(e = r - y\)
